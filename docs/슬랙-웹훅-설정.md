# Slack Incoming Webhook 설정 가이드

`.claude/hooks/notify.mjs`가 Slack으로 알림을 보내려면 Incoming Webhook URL이 필요합니다.
전체 알림 구성은 [알림-설정-가이드.md](./알림-설정-가이드.md)를 참고하세요.

## 1. Slack 앱 만들기

1. https://api.slack.com/apps 에 접속합니다. 이미 Slack에 로그인되어 있으면 해당 워크스페이스가 자동으로 선택됩니다.
2. **Create New App** -> **From scratch**를 선택합니다.
3. App Name에 `Claude Alarm` 등 알아보기 쉬운 이름을 입력하고, 알림을 받을 워크스페이스를 선택한 뒤 **Create App**을 누릅니다.

## 2. Incoming Webhook 활성화

1. 좌측 메뉴에서 **Incoming Webhooks**를 엽니다.
2. 상단 토글을 **On**으로 바꿉니다.
3. 페이지 하단의 **Add New Webhook to Workspace**를 누릅니다.
4. 알림을 받을 채널(예: `#claude-alarm`)을 선택하고 **Allow**를 누릅니다.
5. 생성된 **Webhook URL**을 복사합니다.
   형태: `https://hooks.slack.com/services/T000/B000/XXXX`

## 3. Webhook 단독 테스트

Claude Code 훅을 거치지 않고 URL만 먼저 검증합니다.

PowerShell:

```powershell
Invoke-RestMethod -Method Post -Uri "복사한URL" -ContentType "application/json" -Body '{"text":"webhook 테스트"}'
```

응답이 `ok`이고 채널에 메시지가 보이면 성공입니다.

macOS / Linux / Git Bash:

```bash
curl -X POST -H "Content-Type: application/json" -d '{"text":"webhook 테스트"}' "복사한URL"
```

## 4. 환경변수 등록

URL은 파일에 적지 않고 사용자 환경변수로만 보관합니다.

```powershell
setx SLACK_WEBHOOK_URL "복사한URL"
```

- `setx`는 새 터미널부터 적용됩니다. 터미널과 Claude Code를 재시작하세요.
- 확인: `echo $env:SLACK_WEBHOOK_URL`
- macOS / Linux: `~/.zshrc` 또는 `~/.bashrc`에 `export SLACK_WEBHOOK_URL="..."` 추가 후 `source`.

## 5. 훅 연동 확인

Claude Code에서 실행합니다.

```
/notify-test            # 실제 전송
/notify-test dry-run    # 전송 없이 메시지만 출력
```

Slack 채널에 `🔔 [Claude Code] 프로젝트명` 메시지가 오면 완료입니다.

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 메시지가 안 옴 | 환경변수 미설정이거나 터미널을 재시작하지 않음. `echo $env:SLACK_WEBHOOK_URL` 확인 |
| `notify slack failed: HTTP 404` | URL 오타 또는 Webhook 삭제됨. 새로 발급 |
| `notify slack failed: HTTP 403` | 앱 권한 문제 또는 워크스페이스 정책. 관리자에게 앱 설치 승인 요청 |
| private 채널에 안 감 | 해당 채널에 앱을 초대하거나 채널을 다시 선택해 Webhook 재발급 |
| 앱 생성 자체가 막힘 | 워크스페이스 관리자가 앱 설치를 제한한 경우. 관리자 승인 필요 |

## 보안 주의

- Webhook URL은 비밀번호와 같습니다. 이 URL을 아는 사람은 누구나 해당 채널에 메시지를 보낼 수 있습니다.
- 저장소 커밋, 채팅·이슈 공유를 피하세요.
- 유출되었다면 api.slack.com/apps 의 앱 -> Incoming Webhooks에서 해당 Webhook을 삭제하고 새로 발급합니다.
- 채널을 바꾸려면 **Add New Webhook to Workspace**로 새 URL을 발급해 환경변수를 교체합니다.
